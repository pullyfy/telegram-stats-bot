# MacanyeWest Bot
Telegram-бот для подсчёта статистики сообщений в группах. Считает активность пользователей за разные периоды, строит топы и помогает определять «маканов» - тех, кто мало пишет.

## 📌 Возможности
- Подсчёт количества сообщений каждого пользователя
- Статистика за **час / день / неделю / месяц / всё время**
- Топ-10 самых активных участников
- Проверка, кто не набрал нужную норму сообщений (с гибкими настройками)
- Личная статистика по любому пользователю
- Интерактивные команды на русском языке

## 🚀 Команды бота

| Команда | Что делает |
|---------|------------|
| `/start` | Приветствие, краткая справка о боте |
| `/help` | Полный список команд и их описание |
| `/makan_top` | Показывает топ-10 самых активных пользователей в группе |
| `/makan [@username]` или `макан` | Личная статистика указанного пользователя (или своя, если никто не указан) |
| `/kto_makan <норма> <период> <упомянуть> <процент пощады>` | Список тех, кто написал меньше нормы. Можно настроить упоминания и порог «пощады» |
| `я макан` | Рандомная фраза из базы «маканских» выражений |
| `макан не я` | Выбирает случайного пользователя и выдаёт ему маканскую фразу |
